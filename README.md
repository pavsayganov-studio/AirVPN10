# 🚀 Raketa

Минималистичный VPN-клиент для macOS, работающий из строки меню. Создан для
обхода DPI-блокировок в России через **VLESS + Reality + uTLS** поверх ядра
[sing-box](https://github.com/SagerNet/sing-box) v1.14.3.

Раньше проект назывался PauloVPN / AirVPN.

---

## Что делает

- Подключается к любому VLESS-серверу (Reality) через системный прокси
  (HTTP/HTTPS/SOCKS5) — без TUN-интерфейса и без постоянного демона: помощник с правами root
  живёт только пока открыто приложение.
- Хранит и парсит подписки: одиночная `vless://` ссылка, список ссылок,
  base64 или JSON-подписка в формате sing-box.
- Отдельная поддержка Telegram: MTProxy-подобный порт (10810) и SOCKS5
  (10808) с deep-link кнопками для одного клика.
- Автоматически восстанавливает список серверов при перезапуске.
- **YouTube без VPN (v0.12.0):** кнопка «Смотреть YouTube» включает обход DPI
  (ByeDPI) только для доменов YouTube — остальной трафик идёт напрямую.
  Кнопка 🔍 проверяет сеть «на проводе» (один и тот же адрес Google с именем YouTube и с
  именем Google — видно, режет ли фильтр по имени) и перебирает 10 стратегий разрезания
  потока; кнопка ▾ — результаты и ручной выбор. Fake-пакетов в macOS-сборке ciadpi нет, а
  против современного ТСПУ чистые разрезы, скорее всего, не работают (handoff.md §15).
  DoH включается только если системный DNS не отвечает. Журнал поиска —
  `~/Library/Application Support/Raketa/dpi_search.log`.
- **Тёмная тема (v0.13.0):** интерфейс сам переключается вместе с системой (на 10.13 — по
  настройке «тёмная строка меню»).
- **Быстрые действия (v0.13.0):** правый клик по иконке ракеты в строке меню — подключить /
  отключить VPN, обход YouTube, выйти.
- **Ядра и подписка (v0.14.0):** sing-box 1.14.3 (официальная сборка под macOS 10.13). Кнопка
  «Ядра» — версия ядра, проверка обновления (новое ядро ставится только если оно запустилось и
  приняло конфиги приложения) и возврат к встроенному. Запрос подписки представляется клиентом
  (User-Agent, устройство, HWID), показывает трафик и срок и называет причину отказа; серверы с
  XHTTP / VLESS Encryption (ядро sing-box их не умеет) считаются и показываются как пропущенные.
- **Обход DPI (v0.14.2):** стратегии ciadpi (разрезание потока, «M») признаны нерабочими на macOS и
  заморожены. Новые «S1–S8» запускает сам sing-box 1.14: поддельный ClientHello (`tls_spoof`) и
  фрагментация; нужен root (пароль — один раз за сеанс, см. ниже). Результат — в журнале поиска (▾ → Журнал).
- **Один пароль за сеанс (v0.15.0):** первый шаг, которому нужен root (подключение, YouTube, поиск
  стратегий), запускает маленький помощник одним запросом пароля; дальше переключения VPN ↔ YouTube,
  отключение и выход идут без пароля. Помощник понимает пять фиксированных команд и выходит вместе с
  приложением. Не получилось — приложение спросит пароль на каждом шаге, как раньше. Выключить:
  `defaults write com.samurai.raketa RKSessionAuth -bool NO`.
- **Ускориться (v0.15.0):** кнопка над «Смотреть YouTube» — для старых Mac, без пароля. Кэши старше
  30 дней и логи старше 90 дней из папки «Библиотека» переносятся в Корзину (не удаляются), через неделю
  Raketa удаляет оттуда только свои папки `MacMaintenance-…`, анимации окон / Dock / Finder
  приглушаются (правый клик по значку ракеты → «Вернуть анимации macOS»). Перед первым запуском —
  один раз окно с описанием.
- Watchdog проверяет живость ядра каждые 12 секунд практически бесплатно
  (`kill(pid, 0)`, без форков процессов).

## Обязательные требования

Эти требования были явно установлены в ходе разработки и **не подлежат
пересмотру без явного запроса**:

### 1. Совместимость с macOS
- **Минимальная версия: macOS 10.13 (High Sierra).** Это основная целевая
  платформа — приложение должно работать на ней в первую очередь.
- **Подтверждена работа на macOS 12.x (Monterey, включая 12.7.6).**
  Требует использования `&` вместо `nohup` при фоновом запуске ядра
  (см. раздел «Известные грабли» ниже).
- Архитектура сборки: `x86_64` (Intel). Universal/`arm64` не добавлять без
  отдельного запроса.
- `-mmacosx-version-min=10.13` в `build.yml` — не менять.

### 2. Минимальная нагрузка на CPU и систему
Явный приоритет, стоящий выше визуального полиша:
- Watchdog — только `kill(pid, 0)`, никогда `pgrep` на каждый тик (только
  как одноразовый fallback, если PID не был захвачен).
- Сетевой интерфейс определяется **один раз** при запуске и кешируется —
  никогда не переопрашивается при каждом старте/стопе VPN.
- Никаких фоновых опросов, автообновлений по таймеру или периодической
  сетевой активности. Обновление подписки — только вручную по кнопке.
- Цвета и статичные ресурсы UI создаются один раз (`+initialize`), не при
  каждой перерисовке.

### 3. Архитектура — System Proxy, не TUN
Решение принято сознательно после неудачных экспериментов с `utun`
(двойные пароли, зависания при крахе ядра). **Не менять на TUN/VPN-конфиг
без явного запроса.** Один вызов AppleScript
(`do shell script ... with administrator privileges`) на операцию
старт/стоп — это то, что устраняет проблему двойного пароля.

### 4. Процесс работы над проектом
- Изменения поставляются **только как цельный скрипт** (bash или Python),
  который переписывает нужные файлы целиком и заканчивается точными
  git-командами (`add` → `commit` → `tag` → `push`).
- Никаких диффов, патч-файлов в формате `.patch`/`.diff` или ручных
  инструкций «отредактируйте строку N» — среда разработки это
  GitHub Codespaces, без локального Xcode.
- Каждый скрипт делает резервную копию затрагиваемых файлов
  (`cp X X.bakVERSION`) перед перезаписью и удаляет её после успешного push.

## Структура репозитория

```
├── main.m                          — точка входа NSApplicationMain
├── AppDelegate.m / .h              — NSStatusItem + NSPopover
├── ViewController.m / .h           — вся логика интерфейса и VPN
├── CoreUpdater.m / .h              — обновление ядра sing-box из приложения (кнопка «Ядра»)
├── RKSubscription.m / .h           — запрос подписки: User-Agent, HWID, трафик/срок, понятные ошибки
├── DPIEngine.m / .h                — движок обхода DPI для YouTube (ciadpi, стратегии, поиск)
├── RKRoot.m / .h                   — клиент root-помощника: один пароль за сеанс (v0.15.0)
├── rkhelper.sh                     — сам помощник (bash): пять команд, выходит вместе с приложением
├── MaintenanceEngine.m / .h        — «Ускориться»: старые кэши и логи в Корзину, анимации (v0.15.0)
├── dpi/                            — снимок списков сайтов ByeByeDPI для проверки
├── Info.plist                      — метаданные бандла, версия
├── AppIcon.svg                     — исходник иконки (ракета на градиенте, сетка иконок macOS)
├── generate_icon.py                — SVG → .icns при сборке (cairosvg + iconutil)
├── tools/cleanup_releases.py       — наведение порядка в тегах и релизах (dry-run по умолчанию)
├── .github/dependabot.yml          — еженедельные обновления закреплённых GitHub Actions
└── .github/workflows/build.yml     — CI: сборка sing-box + ciadpi, проверка, релиз с changelog
```

Проект **не использует `.xcodeproj`** — компиляция напрямую через `clang`
внутри GitHub Actions.

## Сборка и релиз

```bash
# Применить очередной патч-скрипт (сам проверит, закоммитит, запушит и удалит себя)
python3 patch_raketa_<ver>.py
```

Релиз собирается вручную: GitHub → Actions → **Build Raketa** → *Run workflow* →
ввести версию (галочка *dry run* — собрать и проверить без публикации). Тег создаётся
только после успешной сборки. Workflow закреплён по SHA, работает с минимальными правами,
скачивает ядро (SHA-256 закреплён), проверяет x86_64 / macOS 10.13 / подпись, прописывает версию в `Info.plist`,
кладёт рядом `.sha256` и пишет changelog из коммитов. Если `ciadpi` не собрался — приложение
всё равно собирается, без функции YouTube.

Порядок в тегах и релизах: `python3 tools/cleanup_releases.py` (показать план),
`python3 tools/cleanup_releases.py --apply` (выполнить).

## Известные грабли (уже исправлены — не переоткрывать)

Подробное объяснение каждого пункта — в `handoff.md`. Коротко:

| # | Проблема | Где искать в коде |
|---|---|---|
| 1 | `nohup` падает на macOS 12 (`ENOTTY`, нет терминала у AppleScript) | `startVPN` — убран, используется просто `&` |
| 2 | `"type": "http"` inbound даёт `protocol wrong type for socket` | конфиг sing-box — используется `"type": "mixed"` |
| 3 | `selector`/`urltest` группы в подписке вызывают reconnect-storm у Telegram | парсер подписки — такие группы фильтруются |
| 4 | Telegram в `direct` не работает (заблокирован), но через VPN с `selector` — виснет | Telegram идёт через VPN, `selector` исключён |
| 5 | Пароль при каждом открытии попапа | проверка `isSystemProxyEnabled` перед сбросом прокси |
| 6 | Имена цветов вида `cText` конфликтуют с `AERegistry.h` (Carbon `OSType`) | все цвета с префиксом `rk*` |
| 7 | Свойство `copySecretBtn` не компилируется (ARC method family) | переименовано в `secretCopyBtn` |
| 8 | `contentTintColor` — только macOS 10.14+ | используется `attributedTitle` |
| 9 | `NSBezelStyleRounded` скрывает Unicode-иконки на малых кнопках на 10.13 | `bordered=NO` + `CALayer` + `attributedTitle` |

## Дизайн

Голубая тема в двух вариантах — светлая и тёмная (следует системе), полностью непрозрачная
(без `NSVisualEffectView`). Форма мягкая (с v0.14.1): капсульные кнопки и поля, нижняя панель —
скруглённая карточка, шапка без плашки.
Типографика и отступы ориентированы на HIG macOS 10.13 (13pt базовый
текст, 11pt вторичный, 9pt микро, 20pt внешние отступы). Подробная палитра
и карта интерфейса — в `handoff.md`, раздел 5.
